# HR Management Database

A relational Human Resource Management Database built using Microsoft SQL Server and SQL Server Management Studio (SSMS).

## Project Overview

This project organizes employee information and connects related HR data through a structured relational database.

## Technologies Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- Primary Keys and Foreign Keys
- INNER JOIN and other SQL JOINs

## Database Tables
- Countries
- Regions
- Districts
- Locations
- Departments
- Jobs
- Employees

## Key Features
- Relational database design
- Connected tables using foreign keys
- Employee and department information
- SQL JOIN queries for combined reports
